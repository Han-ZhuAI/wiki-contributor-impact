# WikiContrib v1.0

WikiContrib v1.0 is the first complete release of the explainable Wikipedia contributor-impact pipeline.

## Included

- Unicode token-level revision diff with gross, net and churn metrics
- Token provenance chaining with exact-revert and partial-restoration handling
- Additive and maintenance edit classification
- Seven-class wikitext element analysis
- Talk-page parsing, reply graph and weighted PageRank
- Four-axis contributor profiles and configurable composite scoring
- Automation-aware ranking comparison with auditable evidence
- CLI, complete JSON export and reproducible PNG charts
- Three-article sensitivity evaluation for Alan Turing, Kimchi and Python
- English PRD, ER design and final report
- CI on Python 3.10 and 3.12 with a 95% coverage threshold

## Verified baseline

- 245 tests passed
- 95.45% total coverage
- Python 3.10 and 3.12 CI jobs pass

## Interpretation limits

Evaluation runs use the earliest 50 article and Talk revisions and are historical slices. Rankings are descriptive model outputs under explicit weights, not ground-truth judgements or causal claims. Automation candidates require manual review.

## Reproduce

```bash
pip install -e ".[dev]"
ruff check src tests
python -m compileall -q src tests
pytest -q --cov=wikicontrib --cov-report=term-missing --cov-fail-under=95
```
